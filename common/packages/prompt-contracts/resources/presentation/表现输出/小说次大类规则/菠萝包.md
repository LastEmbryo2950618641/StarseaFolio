# 菠萝包

> 用途：参考 SF 轻小说/菠萝包的轻小说与 ACG 阅读环境，帮助作品建立角色、题材和关系入口。平台内容会跨题材，本文件不把它限定为某一种恋爱或后宫模式。

## 公开定位与适用范围

SF 官方网站以“SF轻小说”展示原创小说内容，并提供轻小说书库入口；同一生态也覆盖漫画等内容。公开定位说明了轻小说和 ACG 内容是重要入口，不代表每本作品都要使用日系设定或特定关系结构。

## 面向读者的创作建议

- 清楚呈现作品的题材卖点、主要角色、关系张力和情绪主线；让读者容易判断作品会提供什么阅读体验。
- 关系变化建立在具体互动、选择、边界和回应上；避免无铺垫地亲近、信任、决裂或和解。
- 角色的兴趣、能力、身份与日常细节用于塑造行动和声口，不以标签或流行梗代替人物。
- 设定和 ACG 文化引用考虑读者熟悉度；必要信息在故事内部提供，梗只作为增益，不成为理解主线的门槛。
- 轻松互动与情绪高潮互相留出空间，关键场景避免被重复插科打诨稀释。

## 避免

- 把平台等同于单一题材、固定恋爱关系或某种性别向套路。
- 让角色关系只靠设定宣告推进，没有事件、选择和相互回应。
- 为显示“懂梗”而堆砌来源不明或脱离场景的梗。

## 与其他规则组合

本规则关注轻小说/ACG 受众入口和角色关系可读性；小说大类规则决定主要叙事取向，笔风规则决定文字声音。可与爽文或传统文学取向组合，按作品定位调整情绪强度、结构和节奏。

## 来源与适用边界

- SF 官方网站：[SF](https://www.sfacg.com/)，页面提供轻小说栏目与作品阅读入口（访问日期：2026-11-03）。
- 官方主页同时展示漫画等内容，故本规则描述的是重要内容生态而非唯一内容类型。
