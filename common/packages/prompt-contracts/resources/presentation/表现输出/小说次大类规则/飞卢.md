# 飞卢

> 用途：平台受众与内容定位参考。公开页面会变化，本文件是根据当前公开页面整理的创作建议，不代表平台合同、审核细则或全站作品都必须遵守。

## 公开定位与适用范围

飞卢官方作家专区提供原创作品发布、作者指南和大纲设定等创作入口，站内公开分类覆盖多个题材。仅凭这些公开信息，不能推断所有飞卢作品共用一种文风或单一情节模板。

## 面向读者的创作建议

- 让核心卖点足够具体，尽早展示主角目标、独特条件和冲突入口。
- 高概念、脑洞或跨类型设定要能迅速转化为人物行动和可见后果，避免只停在设定介绍。
- 连载章节持续回应读者对主线的期待；阶段性胜负、身份变化和关系变化都应改变后续局面。
- 节奏可以鲜明，但每次推进仍须有因果、人物选择和必要铺垫。

## 本项目明确的感情线硬约束

- **本规则按用户明确要求采用“全处全收”：作品中出现的女性角色均须属于主角的感情线对象。**不得把此项描述成已查证的平台官方普遍规则。
- 感情线必须在正文通过互动、选择、信任和关系变化建立；仅有角色名单或旁白宣称不算完成。
- 女性角色保留独立欲望、判断、能力和行动后果；感情关系不能抹去其主体性，也不能绕过作品设定中已确立的同意与边界。
- 若当前作品构思不接受这项关系设定，应在写入故事内容前向用户澄清并调整本规则选择，不能暗中忽略或擅自改写。

## 避免

- 把“高概念”写成一段设定术语，或用持续升级代替人物与局势变化。
- 把“快”理解为跳过动机、情绪过渡和事件后果。
- 将本项目的感情线要求误称为飞卢官方硬性规定。

## 与其他规则组合

本文件提供平台向读者预期与项目感情线要求；小说大类规则决定主要阅读满足，笔风规则决定叙述腔调。冲突时遵守已确认作品设定和用户指令；如硬约束本身与新构思冲突，先讨论调整规则，不得静默改写。
