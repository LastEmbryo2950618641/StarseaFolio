# 起点

> 用途：结合阅文旗下原创网络文学与编辑投稿生态，帮助作品规划适合持续连载的主线与阶段结构。本文件描述的是创作适配建议，不是平台统一审核标准。

## 公开定位与适用范围

阅文作家专区自述为网络文学创作基地，作者可创建并发布原创作品，并向旗下不同平台的编辑专区投稿。起点作品覆盖多种题材，不能从平台名称推断所有作品都必须使用升级流、系统或某一种性别向套路。

## 面向读者的创作建议

- 明确作品的核心承诺：主角长期追求什么，读者会持续看到哪类变化或问题。
- 把长线拆成阶段目标、阻力、阶段结果和下一阶段的新局面；每个阶段既有局部完成感，也推动长期主线。
- 让设定通过使用逐步展开，重要规则保持一致；每次扩展设定都应改变人物选择、风险或资源。
- 记录重要伏笔、承诺和人物关系变化，并规划回收方式；不要把“以后解释”当成已经铺垫。
- 章节结尾承接本章事件，提出能推动后续阅读的具体问题，不要求机械地每章反转。

## 避免

- 只有庞大世界观，没有可持续行动的主角目标。
- 长期重复相同升级、打脸或任务循环，阶段结果不影响后续。
- 把连载长度误当成注水理由，或把某个流行题材当成起点的唯一题材。

## 与其他规则组合

本规则强调长线连载的可持续结构；小说大类规则决定主要读者体验，笔风规则决定表达方式。短篇或有限篇幅作品也可使用起点次大类，但须按实际篇幅缩小阶段，不强行扩成长篇。

## 来源与适用边界

- 阅文作家专区：[作家专区](https://write.qq.com/)，官方介绍其网络文学创作与原创作品投稿流程（访问日期：2026-11-03）。
- 官方页面证明的是创作平台和投稿生态，不足以证明某一套情节节奏适用于全部起点作品；本文件中的结构建议是为了支持可持续连载。
