# 传统文学

> 用途：在本项目中，“传统文学”是用户选择的文学性/严肃叙事取向，不是“古代文学”的同义词，也不宣称存在一套公认、封闭的分类标准。它可以与网络平台、类型题材和通俗叙事组合。

## 概念边界

文学理论中的“纯文学”“严肃文学”“通俗文学”等概念有各自历史，边界和价值判断长期存在争论。中国作家网关于网络类型小说的研究也指出，简单的“通俗/严肃”二分难以解释当代类型文学的实际形态。因此本文件不把传统文学定义为反类型、反情节或高门槛写法。

在本项目的创作设置中，本规则强调：人物经验、语言选择、社会关系、结构和主题之间形成持续意义；主题从具体生活和行动中生长，而不是靠抽象议论代替故事。

## 读者体验

- 人物有具体处境、欲望、局限和关系，选择会留下可感知的后果。
- 语言、叙述视角和结构服务人物经验与作品主题，不以辞藻本身证明文学性。
- 作品允许含蓄、多义、留白和非单线结构，但读者仍能追踪场景、关系及重要变化。
- 情绪和意义通过细节、重复、对照和累积形成；情节张力与可读性仍然有效。

## 写作约束

1. 重要主题落到人物正在经历的事、具体关系或现实条件中；减少由旁白替读者总结的段落。
2. 选择有辨识度且准确的细节，避免用抽象词、象征物或环境描写遮蔽场景信息。
3. 结构实验须产生阅读上的意义，例如视角差异、记忆断裂或时间并置；交代必要线索，避免把难懂当成深刻。
4. 留白保留解释空间，但不得隐去理解人物选择所必需的因果信息。
5. 章节节奏可以舒缓或紧凑，按人物经验和结构需要安排，不预设必须慢、必须悲剧或必须弱化情节。

## 避免

- 把“传统”误解为古风背景、仿古语言、家族伦理或经典改写。
- 把“文学性”简化为慢节奏、晦涩句子、无结局或拒绝类型元素。
- 通过旁白直接宣告主题，或以抽象修辞替代人物行动和现实细节。
- 因追求开放性而让人物动机、时间关系或事件因果不可追踪。

## 与其他规则组合

本规则规定文学表达的关注点，不规定题材和时代。它可与任一平台次大类及笔风规则组合；平台规则用于理解目标读者和连载形态，不得自动覆盖作品已经确认的文学结构与人物选择。

## 来源与适用边界

- 周兴陆，《“纯文学”观的意义与局限》，《华东师范大学学报（哲学社会科学版）》2019年第4期：[论文](https://xbzs.ecnu.edu.cn/CN/html/2019-4-6.htm)。本文专门讨论“纯文学”观念的历史意义与局限，支持本文件避免将其固化成单一风格。
- 吉云飞，《“爽”及其完成：网络类型小说的存在方式》，中国作家网，2024-11-28：[原文](https://www.chinawriter.com.cn/n1/2024/1128/c404027-40370888.html)。文章指出类型小说与通俗/严肃二分之间的关系并非简单对立。
- 本项目将“传统文学”作为用户可选的写作方向；这是一项产品内操作定义，不取代学界分类。
