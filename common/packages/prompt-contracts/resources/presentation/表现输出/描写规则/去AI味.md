# 去AI味

> 职责：压掉机器腔与模板句，让正文读起来像人写的场面。不管题材腔、笔风词表；那些由笔风规则 / 本作品描写负责。
>
> **完整去味 / 对话 / 人味 / 情绪演出**：以同轮系统规则中注入的 `chinese-webnovel-skills` vendor 原文为准（MIT，StarseaFolio 不擅自删改）。本文件是描写目录里的基线；冲突时以更具体的 vendor 条款为准。
>
> 下文已将多源提示词**去重整合**（信息保留、说法不重复）。逐字原文归档见 `docs/描写修辞提示词-网站原文合集.md`。

## 本轮身份

本文件是描写**基线**，每轮正式推演与创作台讨论都会注入，不论下拉选「自动」还是锁定某一场面卡。
切镜与密度仍由场面卡负责；感官落点时机由 `感官描写.md` 负责；本文件管「别写成 AI 套话」以及修辞/具象写法。
作品专属禁用词、口头禅偏好写在 `表现输出/本作品描写/`，可叠加在本基线之上。

## 硬约束

- **信任读者**：场面已经演出来的情绪/关系，禁止再跟一句作者总结（「他明白了」「这意味着」「真正重要的是」「从这一刻起」「你刚才说了三句话」）。
- **落到具体**：关键情绪用动作、物件、声音、后果承载；禁止空挂「感到一丝XX」「涌起一股XX」「一种说不清的感觉」「他不是不敢他是怕」。
- **对话像说话**：可打断、吞字、说偏一点；禁止人人出口成章、句句金句。
- **对话有功能**：禁止 A 半截话 → B「什么/担什么」→ A 再解释的乒乓球（详见 vendor dialogue）。
- **句式要有起伏**：长短交错；禁止整段同长并列、三连排比感官清单当装饰。
- **意图优先**：保留人物表达的目的、对象与因果；比喻不得偷换原意。作品未设古风且用户未指定时，不擅自写成仿古腔，细则按平台正文规则执行。
- **具体先于归纳**：角色专属意象（如账、棋、债、门、钥匙）必须落在当场的动作、物件、承诺或交换上；禁止在段末用「多了一条账」「又多了一笔债」这类抽象短句替代事件结果。先写谁做了什么、付出什么、拿到了什么，只有角色确实记下条件时才允许使用意象。
- **章末单一钩**：禁止对仗双「他知道…也知道…」升华收束；只留一个动作或一条具体信息。
- **不要为去味而注水**：删套话后用当场证据补上，不要机械换同义词，也不要故意错字装人。
- **比喻总闸**：须来自角色生活经验与当前语域；禁止万能「像一把刀/像潮水」乱贴。细则见下方「比喻规程」。

## 优先杀掉的模板（正文尽量不出现）

### 中文高频套话

- 眼中闪过一丝… / 眼神里写满了… / 目光如炬 / 眸光
- 嘴角勾起一抹… / 嘴角微扬 / 扯出一抹笑
- 心中涌起一股… / 不禁… / 不由自主… / 他感到… / 他意识到…
- 空气仿佛凝固 / 时间在这一刻静止 / 沉默变得沉重
- 映入眼帘 / 只见 / 此时此刻 / 深吸一口气（作万能转场）
- 「不是A，而是B」/「是A，不是B」及变体「不A，是B」「觉不出A，只觉出B」「手/心不是他的」；「声音不大，却带着…」；「带着一丝XX地说」
- **否定排比造意味**：「没有A，没有B」及「没给A，也没给B」等变体；尤其禁止把无因果关系的两项缺失排成齐整句式，硬造冷酷、命运感或金句感（如「刘悠没给她纸，也没给她编号」）。两项事实都要保留时，写清共同事件/制度因果和实际后果；无共同因果就拆开叙述，不能擅自补动作或动机。
- 「取而代之的是…」；「浑身散发着一股…气息/气场」；「命运/齿轮/棋局」收束升华
- 连续堆砌「一丝 / 一抹 / 仿佛 / 似乎 / 显得有些 / 微微 / 淡淡 / 缓缓」
- 人人出口成章、句句机锋；长段一次讲透的推理口播
- 对白乒乓球：「我要担。」「担什么？」——第二句若只搭台阶就删

### 对话正向写法（短）

- 门吏/跑腿：短、白话、躲责优先；信息半句够用，其余用插牌、退步、抠漆。
- 勿用舞台腔半截悬念（「我要担」）逼对方追问；要说清就一次说清，或干脆不说改动作。
- 可不通顺，不可无功能：答非所问、打断可以；无来由的「什么意思」接力不行。

### 英文/翻译腔常见 AI tell（若正文出现英式转写也禁）

- a sense of… / couldn't help but (feel) / a pang/wave of… washed over
- eyes widened / heart pounded in his chest / let out a breath he didn't know he was holding
- the air was thick with… / piercing … eyes / a knowing smile

## 正向替代（原则，不规定用词）

- 要写怒/怕/欲：写手、呼吸、距离、物件、话说到一半停住——不要贴标签。
- 要写好看/可怕/臭：落到观察者当场看见或闻到的一点（与 `感官描写.md` 配合），不要只说「很好看/很可怕」。
- 场面结束后直接切下一动作或对白；不要加旁白讲课。

## 不做的事

- 不规定必须冷峻、必须口语、必须短句——那是笔风规则的事。
- 不要求每句都「骚操作」；过场可以平。
- 人物对白里允许说套话（若符合性格）；作者叙述禁止套话。

# 整合规程（去重后的高密度条款）

> 下列把多源提示词合成一套可执行规程。冲突时取**更严且更具体**的一条；用户本轮明确指令优先。

## 一、展示 / 感官 / 起草锚（合 B·C·E）

### 1.1 告诉式 → 展示式

标出并改掉：直接情绪词（她很害怕）、直接下判断（他吝啬）、概括描写（房间很乱）。

改写要求：
- 动作用身体反应代替情绪词（手心出汗、反复检查门锁）
- 具体细节代替概括（泡面桶摞到窗台，不是「很乱」）
- 五感：视觉之外至少再动用声音 / 气味 / 触感 / 温度中的两种
- 细节必须经视角人物过滤（失业者进咖啡馆先看价格，不是装修）
- 过渡、时间跳跃、不重要动作可保留简洁叙述；高潮多展示，过场可叙述
- 改写篇幅 ≤ 原文 1.5 倍；不增新情节

啰嗦 → 每个情绪只留一个最有力细节。俗套（眼泪夺眶）→ 换成只属于此人此景的细节。

### 1.2 感官锚点工作流（防「生动却千篇一律」）

1. **先列事实边界**：地点时间、在场谁、视角在做什么、已确立细节；标出「可建议但不可当既定事实」的项。例：黄昏候车亭、雨后、玛拉独等、路面湿、车未到；勿加路人/城市名。
2. **选 1–2 个感官锚 + 场景任务**（放慢 / 不适 / 引入环境 / 指向即将发生的事）。不要五感打卡。
3. **模型可最多建议 2 个额外感官**，必须标成「建议」而非事实。
4. **先审事实再润色**：每条感官问——笔记里有吗？由既定事实可推出吗？视角此刻能注意到吗？服务场景目的吗？纯装饰就删。
5. **嗅/味/触/听尤慎**：袖口湿贴合理；面包店气味必须有店；车未到就不能写引擎声（除非另有声源）。

反例（越界）：凭空加风、驶近公交车、金属味、霓虹。  
紧例（贴锚）：雨水敲顶棚；袖口贴腕；候车亭外路面反光；车还没来。

### 1.3 场景五要素起草（防概述、防语域漂移）

写场景时内部须具备（创作台不必输出英文标签）：

| 要素 | 作用 |
|---|---|
| 类型标记 | 锚定散文语域（哥特恐怖 / 温馨推理 / 硬科幻…） |
| POV | 第一人称或紧密第三人称·姓名；观察经一个意识过滤 |
| 感官锚点 | 一个具体感官（湿混凝土味、钟滴答、地毯磨损触感） |
| 情感节拍 | 落点情绪 +「只演不点名」 |
| 字数上限 | 压缩 150；完整节拍 250–300；单场景 ≤400，超出另开一场 |

战斗/动作可选加强：每句 ≈ 故事时间 1 秒，100–200 字。

模型常在 200–300 token 后滑向通用 AI 语域——用类型+POV+感官+字数钉住；系统提示里写死类型/POV 比用户轮次重复更稳。

## 二、机器腔表面（合 F·L 非比喻部分）

### 2.1 节奏

- 连续 ≥3 句长度相近 → 必须打断：插极短句，或插一带从句的长句。
- 禁「观点+展开+例证+总结」四拍成段；段落长短要参差。
- 健康参考：一段内最长句 ÷ 最短句 ≥ 3；通篇要有 <8 字碎句与 >30 字长句。

### 2.2 排比 / 同构 / 连接词 / 绝对判断

- 对仗排比不要超过两组连用；四字格勿三连串（公文/AI 通病）。
- 连续同构分句 ≤2；连续「主语+动作」≥3 句必改。
- 砍半连接词：然而 / 不仅如此 / 更重要的是 / 换言之 / 由此可见 / 首先其次最后（非刻意分点时）。
- 允许不确定：「可能有争议」「没完全想清楚」；勿句句斩钉截铁。
- 结尾勿文明升华；用具体画面、小问题或从前文长出的余味收。

### 2.3 AI 高频词（优先替换）

赋能→帮到/推动；毋庸置疑/不言而喻/显而易见/综上所述/由此可见/值得一提的是/不难发现→删，直接说事；至关重要→很关键；本质上→说白了；深远影响→影响很大；鉴于此→所以。

### 2.4 套词密度 / 盖章句 / 系统公告腔

| 病 | 改法 |
|---|---|
| 仿佛/一丝/一抹/深吸一口气/平静无波/指节泛白成串 | 不换同义词；整段回到文件、动作、对话、物理后果 |
| 「关切得恰到好处」「笑得恰如其分」「不多不少」 | 作者盖章；只写动作，装不装留给读者 |
| 「那点笑她看得分明」「谁都看得出他在撒谎」 | 点破潜台词；留着别挑明 |
| 抽象升华（命运/宿命/注定） | 用具体事件代替 |
| 系统公告硬词成片 | 保留为角色看见的屏幕/公告载体；载体内白话化，或补当场看懂的后果，勿改成叙述者讲解 |

核心自检：**正常人坐电脑前想了想，会这么写吗？** 不太会 → 改。

## 三、克制·具象·功能优先（合 G；比喻频率见第四节）

核心理念：克制、具象、功能优先。摒弃浮夸修饰、过度抒情与未授权铺垫。

### 3.1 语言

- 词汇：基础常见；避华丽、生僻、过度诗意。
- 句式：简洁陈述为主；避冗长复杂句、排比、过度修辞的疑问/感叹。
- 语感：冷静抽离；作者勿惊叹感伤。
- **术语**：未经用户许可禁止赛博/科幻/魔法行话；效果用功能描述或用户代称（「操作设备绕过安全程序」≠「骇入」；「手中凝聚高温光团掷出」≠「火球术」）。用户明确定义后可在授权范围内用词，仍忌围着术语扩写。

### 3.2 物品

只写物理状态、功能、与角色/场景互动：颜色材质新旧破损用途位置是否被操作。  
禁拟人、象征、情感投射、未授权历史（「忠诚的消防栓」「冰箱疲惫呻吟」「水龙头流下城市的泪」）。

### 3.3 外貌白描

只写可观察且与当下相关的显著特征：性别、年龄范围、体型、发型发色、显著面部特征、穿着、配饰装备。  
禁：推测（饱经风霜）、审美判断（英俊丑陋）、情感映射（忧郁的眼睛）、比喻修饰（星眸、刀削面庞）、未授权前史暗示（老茧暗示工人——除非用户设定允许）。

### 3.4 心理

只写外在可观测：动作化、对话化、细节化、谨慎生理化（喉结滚动）。  
禁：「他想…」「她感到…」「内心…」「回忆起…」。

### 3.5 人物前史

不得自行添加/暗示过往、身份、技能来源、关系网；唯一来源是用户设定或即时指令。焦点：当前场景状态、目标、行动、对话。  
（若与本项目已读设定/图证据冲突：以创作台证据与用户指令为准。）

### 3.6 环境五要素

仅用：天气、光线、气味、声响、空间布局。每次选最相关 1–3 项；服务情节/角色状态/世界观，不单纯写景。  
禁拟人通感（天空在哭、寂静在尖叫、充满绝望的气息）。

### 3.7 禁止预埋

不得擅自引入用户未提及的新元素/线索/势力/地点/重要物品。伏笔与支线设定权归用户。

### 3.8 违规修正

删除违规修饰/比喻/心理/背景暗示/非五要素环境/预埋 → 换成基础功能描述、可观察白描、具体动作对话、五要素客观环境。  
疑虑时选更保守、简洁、功能化的表达，或问用户。

例：  
「旧钥匙仿佛承载流浪岁月」→「他掏出一把铜制旧钥匙」（可加用户设定的磨损）。  
「绝望压迫神经的仓库」→ 寒气、故障灯频闪、铁锈灰尘味、管道滴水；人物反应放后续动作/对话。

## 四、比喻规程（合 A·D·H·I·J·K·L·M·N·O·P；专治不相干喻体 / 跳腔）

### 4.1 何时用、用多少（各源阈值取并集，同时满足）

| 层 | 规则 |
|---|---|
| 功能门 | 每个比喻先问：让读者更懂、更爽、更有画面了吗？没有就删。爽文优先具体动作，不优先比喻。 |
| 段内 | **一段最多一个**比喻/成语；该段内禁止第二喻、禁止「像A。像B。像C。」链。 |
| 延伸 | 同一喻体延伸 ≤2 句；超过多半在秀聪明。混喻（雷区+溺水+搭桥）→ 只留一条车道。 |
| 章/千字 | 健康 **≤3 次/千字**且不连用；连续 2–3 句带比喻 = 污染。明喻预算约 **每章 3–4 个最强**，>6–8 过载；一段 >2 个红灯。（更严操作手册另有「每 500 字 ≤3 处」——与上列同时遵守时取更稀。） |
| 场合 | 优先：极端情绪、重大转折、关键战斗/命案、难以直写的超常现象。日常对话/普通环境铺陈默认不用。 |
| 用户指令 | 用户明确要求「此处加一喻」→ 不受频率限制，但仍过 4.2–4.4。 |

改密不换喻：超标时保留最能传信息/情绪的一两个，**其余改回动作、物件、声音、后果**，不要换成新比喻。比喻是重音；满篇重音等于没有重音。

### 4.2 本体—喻体三问（牵强就删）

任何一句答不上来 → 删，改直说；想留则换日常可感知喻体（牺牲新奇换准确）：

1. 本体和喻体**共享哪个具体属性**？说得出名字吗？
2. 该属性是本体**最需要被说明**的那个吗？
3. 喻体是否比本体**更好懂**？（读者还得先想象喻体 = 负分）

病例：数字「轻」像发尾；叶脉像睫毛——维度不对。

预防六条（从零写）：一名最多一定语；比喻先过三问；同构分句 ≤2；精确数字后文要用到；每段能答「推进了什么」；细节过替换测试。

### 4.3 角色来源域（禁止作者比喻冒充角色）

- 角色打比方调用的是**他的人生素材库**：出租师傅→早高峰二环；程序员→逻辑跑不通；生意人→赔本/周转。
- 每人定 **≤5 个擅长域**，比喻原则上只从这些域取。厨子→火候配料；木匠→承重地基；赌徒→赔率筹码。全员都说「爱是旅程」= 同一人。
- 自检：这个比较来自**此角色**会知道的世界吗？没见过海就别比浪潮。爱上一喻时优先**翻译进角色域**（莫奈日落 → 农夫「今年最后一场好收成，全是金的，而且快没了」）。
- 情绪高峰最易滑回作者词库——尤其要查。对白里的比喻大声读：这角色嘴里说得出口吗？
- 勿职业刻板到只剩行话；智力通过**域内**表达，不是塞作者大词。
- **为谁服务**（文化语境）：比喻是「特定角色 × 特定世界」向受众翻译经验。问：服务谁？翻译什么？需要什么共享语境？直写是否更好？菲律宾片场角色不宜「耳朵像狐狸」——当地无狐，听觉联想也不落在狐上。

正例方向：村医学徒看大军 → 庄稼疫病从田边往里吃，不是「钢铁海啸」；十二岁孩子看废屋 → 「有人开始擦掉它又半途弃了」，不是「熵的墓碑」。

### 4.4 语域一致（轻松忽然铁血 / 学术 / 梗污染）

本质：register 不一致。

**硬句：比喻里的用词（温度、杀气、文白、学术度）必须与当前章/当前笔风同档。** 轻松日常段禁止突然铁血/公文/论文腔喻体；冷硬段禁止突然软萌或鸡汤喻体。喻体选词与全文风格不一致时，宁可直写，也不为“出彩”跳腔。

判断：
1. 这个叙述者/角色**会知道、会这么说吗？**
2. 和**全文语气**一个频道吗？
3. 这个喻体的**用词温度**，和本章正在用的笔风同档吗？

规则：先定语域（朴实/华丽/古风/现代/冷感/俏皮）全文统一。通俗少掉书袋；古风禁现代梗；现代禁硬塞古诗酸文；市井第一人称禁超认知概念。**风格一致 > 单句出彩**。

❌ 都市朴实里塞《追忆似水年华》；古风里「气场全开 MBTI 之王」；轻松闲聊忽然「像刃口舔血」「像军令状」。  
✅ 头也不回走了 / 「退下。」 / 闲聊段用生活口语喻，或干脆不喻。

### 4.5 性质：具象生活经验；禁抽象宏大跨域

允许（关键场）：怒吼像生锈金属摩擦；光晕如破碎霓虹闪烁；恐惧像冷雨浸透。  
禁止（日常/空泛）：笑像暖阳、思绪如羽毛、街道像伤疤（除非用户指定的关键象征地）；禁宇宙/海洋/星空/深渊类宏大跨域充数。  
禁感官域在一句里对撞（火+水意象同句易糊成静电）。

### 4.6 旧喻 / 万能喻 / 定性盖棺喻 / 流水线外貌神态

**直接删改：**

| 类型 | 例 | 改法 |
|---|---|---|
| 兵王/网文旧喻 | 放归山林的猎豹；灵魂撕碎的剧痛；火星落寒潭的泪 | 肢体发力、路面触感、换气、生理反应 |
| 万能喻 | 像潮水般、如闪电般、仿佛春风 | 优先不用；确需则生活化、角色化 |
| 定性盖棺 | 「像在宣判早已定好的事」「像看一件死物」 | 非角色此刻强烈主观就删；要留只能是带偏见的瞬间感觉，非客观断言 |
| 流水线外貌 | 冷白锁骨、宽肩窄腰、锋利鼻梁连环 | 只留一个特征，绑刚做完的事/伤痕/衣着失常 |
| 眼神嘴角套话 | 眼底精光暴涨、嘴角勾起森然弧度 | 手头停下的动作、收起随身物、脚步移动 |

### 4.7 混喻与叠喻（一图打穿）

- 叠喻：「心是堡垒，墙是背叛的石，护城河是泪，龙是猜忌」→ 留「堡垒」，可用「没留门」延伸，勿加龙。
- 混喻：「在情绪雷区游泳还搭桥」→ 读者脑报错；改成单一持续图（「晚宴人人有枪，没人知道谁带的子弹」）。
- 好的单喻可跨感官类别（寂静厚到能靠；悲伤有湿羊毛的重量）——但必须过三问 + 角色域 + 语域。

### 4.8 比喻扫描口诀（改稿）

1. 标出所有像/似/仿佛/宛如/犹如/如同/好比  
2. 过功能门 → 三问 → 角色域 → 语域 → 密度账  
3. 超标：留最强，其余改直写；混喻叠喻拆到一条车道  
4. AI 味指数里「比喻密度」权重中等：连用或超 3/千字约 +1.3；优先改分最高的 1–2 项

## 五、可复制改写模板（合 B·C·E·Q；需要时整段粘贴）

### 模板 S｜Show 改写

```text
请用「Show, Don't Tell」改写。
- 场景：[ ]
- 视角人物：[ ]（人称）
- 情绪或氛围：[ ]
- 文风：[简洁冷峻/细腻抒情/轻快幽默…]
- 原文：
[粘贴]

完成：①标告诉式 ②按动作/细节/五感/视角改写 ③标出应保留的简洁叙述 ④对照表：原句|改写|手法 ⑤全文≤1.5倍，不增情节。
```

### 模板 C｜感官锚点改写

```text
以[角色]视角，受限第三人称改写。
场景事实：[列表]。不要添加人物/对话/地名/新事件。
目的：[ ]（勿直接点名情绪）
我提供的感官锚点：[1–2个]
可建议最多两个额外感官，改写后标为「建议」而非事实。
≤100词。具体名词动词；避免形容词堆与俗套。
草稿：[ ]
另附：新增虚构细节清单。
```

### 模板 E｜五要素起草

```text
Genre: [ ]
POV: [first / close third, name]
Sensory anchor: [one]
Emotional beat: [演出来，不明说]
Word ceiling: [150–400]
Write the scene. Do not summarise. Every sentence must render a moment.
```

### 模板 R｜类型语域转换（轻松↔铁血等）

```text
Source register: [ ]
Target register: [ ]

Rewrite in [target]. Do not change plot. Word ceiling: same as input.
[粘贴段落]
```
