# 感官描写

> 为动作、环境和人物反应提供可感知的细节参考。

## 本轮身份

本文件是描写**基线**，每轮正式推演与创作台讨论都会注入，不论下拉选「自动」还是锁定某一场面卡。
按场面、人物视点和作品语气决定哪些感知值得写，以及是否需要展开。

## 描写思路

- **挑人物在意的细节**：当感知能让读者理解情境、感到变化或体会人物反应时，可写进动作、对白或叙述。详略随场面调整。
- **限知优先**：只写观察者当下能闻到、看见、听见、触到、尝到或身体直接感到的；不得为凑感官泄露其不知的信息。
- **重现时关注变化**：一个对象再次出现时，从当下不同的处境、感受或细节写起，省去已交代过的描写。
- 不改世界事实；禁止把「镜头推进 / 切到特写」写进正文。

## 可以考虑感官描写的场面

### 人与人

- **距离或关系发生变化时**：可写人物察觉的呼吸、衣物气息或动作变化。
- **初次看清重要人物时**：发色、袖口、姿态或伤疤都可建立辨识度，选与此刻有关的细节。
- **对方换了衣服 / 第一次以这身装束出场**：落到衣装的形色、质地、新旧、是否合身、是否沾污等可见处一点。
- **身体接触刚发生或性质变化时**（拉住、推开、擦伤、体温传来等）：落到触感或温度，不只写动作名。

### 人与物 / 环境

- **进入关键空间或环境突变时**：可用空气、光线、声音或气味让读者感到空间和变化。
- **第一次拿起、穿上、吃到、踩上关键物件**：落到触感、重量、温度、味道或声音中与剧情有关的一点。

### 刺激性场面（首次或剧情要求停住时）

当感知本身关系到人物反应或读者体验时，可按场面选择细节：

- 血腥、伤残、尸体与体液
- 恐怖、惊惧、不洁与压迫感
- 黑暗、眩光、烟尘、浓雾
- 恶臭、腐气、刺鼻化学味
- 强烈的美、华丽、醒目衣装或场面
- 色欲 / 色情张力下的身体感知（气味、体温、触感、呼吸、布料等）——仍服从限知与用户规则/细纲禁笔，本文件只要求「有感知」，不规定尺度与措辞

## 不做的事

- 不教如何比喻、不列必须用的意象词。
- 不要求每段五感齐全；与当前动作无关的感官可以不写。
- 不替代 `本作品描写/`：作品级持续偏好（固定体味设定、禁用某种感官夸张等）由用户或讨论写入本作品描写。
