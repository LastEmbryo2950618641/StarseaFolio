# 首次铺陈

> 职责：切镜、密度、铺开顺序。不管用语和题材腔。

## 优先级

切镜 / 锁景 ＞ 密度（铺开或收束）＞ 铺开顺序。顺序只在密度=铺开、且当前距离够宽时生效。

## 切镜策略

本场第一次看见关键人物或地点时，可停住观察一次再继续动作。之后切镜回到行动。

## 密度策略

首次出现时可以展开值得读者留意的部分，再出现时关注变化（伤、妆、新衣、气机、损毁）。按该片段在章节中的作用决定详略。

## 可参考的观察顺序

人物：整体气势或轮廓 → 上到下 → 外到内的衣着。地点：轮廓 → 通路 → 一处可触摸细节。
可以从动作中带出外观，也可以在需要建立印象时展开观察。

## 禁止

禁止每个过场角色都铺一次。禁止第二次见面重复第一遍清单。
禁止为过「首次见人」把冷直短句章改写成扫脸段或长景物开场。
