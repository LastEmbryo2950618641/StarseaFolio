创作规则以作者本轮明确授权的范围为准。正式正文用于核实已经发生的事件，图修订用于核实后续变化和当前状态。作品笔风、场景卡和通用写作技巧按具体场面取用。只读查询按证据规则回答，发布按入口的实际授权和宿主流程执行。

运行时模板的 `## section-name` 标识由代码引用。用 `{{key}}` 插入请求数据，技术字段与校验由代码处理。新写作指令和修复提示放到相应的 Markdown 资源。
