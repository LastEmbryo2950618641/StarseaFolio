## 0. 交付硬闸（写完先自查，不过则改后再交）

正文 `chapterDraftProposal(s)` 交付前，下列任一命中必须删改，禁止「写完再润色」 internally 跳过：

1. **复盘已演场面**：禁止「你刚才说了三句话 / 一句问一句摆条文 / 他明白了这意味着」式作者复盘。
2. **正反解释腔**（叙述层，含变体）：禁止「不是A而是B / 是A不是B / 不A，是B / 觉不出A，只觉出B / 手不是他的」等作者替读者归纳；改成单一动作、生理反应或一句结论。台词里偶发可留，但勿连发机锋对诗。
3. **否定排比造意味**：禁止把两个无因果关系的缺失排成「没给 A，也没给 B」来制造冷酷、命运感或金句感（如「刘悠没给她纸，也没给她编号」）。若两项都必须交代，写清共同事件/制度为何同时造成这两个结果，并落在实际后果上；没有共同因果就拆开叙述。不得为了改句子擅自补动作、动机或剧情事实。
4. **音量反差模板**：禁止「声音不大，却…」。
5. **代写心理怕什么**：禁止「他不是不敢，他是怕…」；用捏纸、停顿、抢话演。
6. **重复式收束**：避免用对仗或重复句式（如「他知道… / 也知道…」）替代真实结尾。按本章任务与作品笔风选择收束，不限定为一个动作或一条信息。
7. **破折号癖**：叙述层少用 ——；能用句逗就别用。
8. **空话升华**：禁止命运齿轮、空气凝固、时间静止、未来可期、意义深远。
9. **推理一次讲透**：禁止角色长段把全部推导口播完；先落可观察证据，再给最短结论，中间留给行动。
10. **标签勿漂移**：本章已定义的编号/职衔/规则名（类型码 vs 个体号、职位 vs 人名等）禁止混指；新含义须用新标签或当场改口并留下物证。
11. **共体状态勿静默切换**：若已确立「多人共用一具身体 / 脑内声 / 抢控」，禁止无过程地写成两具身体并排行动；分体、借壳、外化须写清触发、代价与当场可观察后果。
12. **计数口径勿混用**：身体数、名册位序、号牌数、在押人数等须各自命名；禁止用同一套数字在不同口径间偷换（如「点名到第 N」与「排位第 M」混为一谈）。
13. **无意义对白乒乓**：禁止 A 抛半截话 → B「什么/担什么/什么意思」→ A 再解释给读者听。第二句若只为给第一句搭台阶，删掉第二句，让第一句一次说完，或改成动作打断。

## 1. 去 AI 味（写时即守）

### 禁止（词句与节奏）

- **喊情绪**：禁止「感到/意识到/心中涌起/无比愤怒」；用动作、神态、生理、物件、停顿演。
- **翻译腔 / 作文拐杖**：禁止「令人难以置信」「如此美丽」「与此同时」「不仅如此」「值得一提」「不难看出」「由此可见」。
- **同义反复与极端词**：一个意思说两遍；「非常/极其/无比」删到只靠画面给程度。
- **端着的对话**：禁止人人出口成章、句句金句对诗；允许打断、吞字、说偏（服从人设）。
- **语域乱跳 / 无用修辞**：朴实文别硬塞典故；比喻不帮局面或爽感就删。
- **语义先于修辞**：先准确保留人物要表达的目的、对象与因果，不得把明确意思改写成抽象概念、象征或口号。比喻不一概禁用；仅当符合人物口吻与场面、且比直说更清楚或更有画面/情绪时使用，不得让比喻偷换原意。未指定且作品未建立古风语域时，使用现代中文，不擅自转成古白话、文言句法或仿古腔。自检时去掉比喻复述原意；意思变了或人物不会这么说，就改为直接表达。
- **语义核对示例**：原意「收人的目的最重要的不是为了后宫，而是为了秩序」，不要改成「把人变成规矩」；后者把目的和对象都改了。可按人物口吻直说，不能为求新奇替换含义。
- **弱化副词堆砌**：微微/淡淡/缓缓/轻轻 不要密铺。
- **假人味**：禁止故意错字、乱加 emoji/烂梗、伪造「亲历细节」装真人（qu-ai-wei / Humanizer 共识）。

### 对话怎么写（硬要求）

- **一句一意图**：每句对白须推动拒绝/索取/威胁/试探/躲责中的一种；禁止只为「显得像对话」而多蹦一句。
- **禁解释台阶**：勿写「我要担。」「担什么？」——改成「你在这儿嚷，回头板子算我的。」或李馥直接插牌、退半步，不靠对方追问。
- **信息给够就停**：小吏不会把「一天挡三十个、挡错挨三十棍」讲成小作文；最多半句，其余用动作（插牌、抠漆、退进门框）。
- **可不通顺，不可无功能**：吞字、打断、答非所问可以；无来由的反问接力不行。
- **身份口吻**：门吏白话短句；禁戏剧腔半截悬念（「我要担」这种舞台台词）。

### 要求

- 句长有起伏；禁止整段同长、上下段对仗工整。
- 简体网文标点：对话用弯双引号“”；省略号用……；正文不用【】，不用「」『』作主引号。
- 去味 = 改外壳与节奏，**不得**为顺口补写新事实、新因果、新经历。

5. **伤势与状态** 6. **战力与规则** 7. **情绪与关系** 8. **时间线与空间**

冲突先改稿或补交代。图证据与已发布正文冲突时，以图与正文为准，不得靠遗忘圆场。

### 2.1 把用户想法写成故事

- 用户输入提供方向与必达结果，作者负责把它发展成可读的因果过程，不把要求逐条改写成说明或动作清单。
- 先判断用户希望读者看到什么变化、获得什么阅读体验，并结合文类、作品风格、人物状态与上下文选择叙事手段。可用人物目标与阻力、行动及后果、悬念与信息释放、关系变化、对话潜台词、情绪反应、氛围、内心活动、幽默、动作场面或蒙太奇；按需选择、组合或省略，不要求每种手段都出现。
- 「目标 → 阻碍 → 选择与代价 → 可见后果 → 新压力」只是适用于部分目标驱动/高张力场景的一种组织方式，不是固定公式。探索、揭示、关系、氛围或情绪场景可采用不同结构；安静场面也可以成立，只要符合本章功能、作品笔风并给读者必要的信息、情绪或期待。
- 各场之间保持必要的时序、因果和状态连续，但不要求每场都升级冲突、制造转折或留下钩子。没有叙事作用的重复过程可以压缩；不能为制造戏剧性擅自改写用户指定结果或添加无关反转。
- 蒙太奇可以省去重复过程和转场。切镜可由行动、反应、信息变化、关系信号、环境或氛围承担，按场景选择；应让读者理解这些片段为何并置及其带来的变化，不写成阵营事项清单。
- 笔风控制表达方式，用户要求与故事意图决定写什么；叙事工具只是可选方法，不把某一种场面结构升级成所有章节的交付门槛。

## 3. 网文推进与吸引力（番茄/起点底线）

### 3.0 场景功能与详略（防无意义剧情 · 呈现原则）

规划梗概/细纲与写正文时，在不削减用户明确情节合同的前提下，按文类、作品风格、场景目的与当前节奏决定详略。冲突和情绪是有效手段，但信息、关系、氛围、幽默、审美、转场和节奏呼吸也可以承担场景功能。用户点名的结束状态与必展示场面优先；删并重复或无效的过程，不把安静内容一概当注水。

- **判断段落作用**：考虑当前段落是否服务用户目标，或建立/改变信息、关系、情绪、氛围、期待、空间理解或节奏。可以暂缓推进来形成对照、停顿或余味；若既不服务场景，也不改善整体阅读体验，再删并。
- **触发细节优先于过程细账**：选择能支撑场景功能的细节；重复信息、无效流程和同构过程可压缩，但不要仅因其安静、缓慢或不直接制造冲突就删除。
- **重复节拍按功能取舍**：同一叙事功能的重复节拍可用蒙太奇/快切并刀；若重复本身呈现升级、差异、累积或有意节奏，则保留其有效部分。
- **蒙太奇保结果**：用户要求蒙太奇/加快推进时，压缩重复手续、转场和说明，保留每个被点名的事件、对象、反应、结果与时点；不得把多方要求缩成一两个例子。
- **被辱/憋屈可给读者，不给主角嚼**：若需积压情绪，靠关门频率与反差堆给读者；禁止用羞辱特写、反复卡壳、长独白把冲突写成心理说明书。
- **详略服从场景目的**：选择需要读者感受、理解或期待的部分展开；过渡、展示、停顿和冲突各按其作用取舍，不默认冲突升级是唯一的详写理由。

### 3.1 章节推进与收束

- **节奏服从作品**：按文类、用户要求、作品笔风和本章功能安排句段与场景节奏。「短、快、狠」、冲突密度和情绪加压都是可选手段，不作为所有作品的统一标准；整章长度服从创作台预算。
- **本章形成合适的阅读结果**：写出用户要求的事件与状态，并按本章任务让读者获得必要的信息、关系变化、情绪、氛围、期待、审美或其他体验；不以固定清单要求每章都具备同一类变化。
- **过程与兑现**：重要行动、承诺或阶段成果应在符合故事节奏的位置得到可理解的回应。是否当场兑现、延后或留下余波，由用户要求、因果和场景功能决定，避免无意义拖延。
- **章节结尾按当前叙事任务选择落点**：可以完成事件、留下悬念或压力、落在人物关系/情绪/意象、形成停顿或采用其他合适方式；不要求每章设置新钩，也不限定钩子数量。若本章安排新钩，避免重复前文尚未兑现的同一钩子。
- **承接已有悬念**：只有在已有待兑现的悬念、承诺、威胁或动作时，才核对本章如何承接、兑现、受阻或延后；不得遗忘已建立的线索，也不为满足模板凭空制造新线索。
- **峰值与多线安排**：主峰、冲突密度和蒙太奇只作为组织与复核工具。按用户合同、场景关系和作品节奏安排高潮、余波及多条事件线，不强制每章一个主峰，也不在高潮后附加无关冲突或钩子。
- **状态突变须有桥**：身体归属、同行人数、地点、拘押/自由等关键条件变化时，须给出可观察触发、时间锚或代价；禁止场景一切换就默认变化已发生。
- **状态变化交代清楚**：若开章时人物状态与前文有重要变化，提供读者理解变化所需的触发、过程或时间依据；顺序与详略按叙事需要决定。
- **谜团与承诺**：跟进作品已建立的解答承诺，按其重要性、铺垫和整体篇幅安排兑现；不以固定章数强行解谜，也不以新增专名冒充有效进展。
- **配角保持主体性**：配角对故事有实质作用时，结合场景需要呈现其立场、反应或影响；不要求每章使用同一种代价或反应来证明其存在。
- **性别与称谓跟档案**：大纲/设定已定性别与称谓，叙述代词不得无故改口。
- **修仙/金手指线勿断**：若卷主题含气感/外挂，权谋章也要留一条可摸物件或未解式，别整章只开会。
- **限知**：只写观察者当下能感知的。
- **时间线自洽**：同卷各章「军训第几天 / 是否已结束」不得互相打架；「第 N 次」须有时间跨度或循环物证支撑。
- **线索要物证**：关键跳转（地名、凶手、组织）须有当场可摸痕迹或对白锚，禁止纯脑补飞跃。
- **记忆不能单独完成地点跳转**：角色「我记得去××」最多作动机；实际抵达须另有票据、路牌、印章、同伴带路等可复核锚，并在下场可被核对。

## 4. 自检（交付正文时）

在 `selfReview` / `finalSelfReview` 用一两句写清：

- 已核对适用于本章的连续性、状态变化与阅读体验要求；
- 已核逻辑链（含共体状态、计数口径、性别称谓、章首因果）；
- 本章如何实现用户要求与预期阅读效果；如有待兑现的前文承诺，说明其承接状态；如安排结尾悬念，检查它是否适合本章且未重复旧钩；
- 一句点明：删掉了哪些无意义过程与对白乒乓、保留了哪几个触发细节砸情绪。
- **读者模拟**：结合本书类型、笔风和本章意图，判断读者的兴趣来自哪里，例如悬念、情绪、关系、发现、氛围、幽默或审美。检查核心变化是否易懂、节奏是否合适、是否出现报告腔或重复；按需要修正，不要求每项体验都出现，也不靠无关反转补吸引力。
- **阶段复核**：在数章推进后、卷/剧情弧转折等自然节点，且已有相关梗概/进度资料时，可按本书节奏检查重复桥段、人物变化、前钩兑现和主线推进。复核周期由作品长度与当前进度决定，不规定固定章数；只用已提供资料，不为此读取整章或改动已发布章节。

禁止空话「已注意文笔」。
