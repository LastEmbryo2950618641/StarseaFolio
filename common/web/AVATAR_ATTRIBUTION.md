# Avatar attribution

The predefined avatar choices use Twemoji v17 PNG assets hosted by jsDelivr:

- Project: https://github.com/jdecked/twemoji
- Asset source: https://github.com/jdecked/twemoji/tree/v17.0.2/assets/72x72
- Graphics license: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://github.com/jdecked/twemoji/blob/v17.0.2/LICENSE-GRAPHICS

Each selected image is copied into the account profile as the account avatar. Users can also upload their own image.
