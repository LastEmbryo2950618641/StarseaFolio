# 爽文

> 用途：确定读者从冲突与结果中获得的主要满足感。它是叙事取向，不等同于某个平台，也不等同于“主角一直赢”。加载本文件后，将下面的读者体验和场景检查用于梗概、大纲与正文。

## 概念依据

网络类型小说研究将“爽”讨论为特定读者在受限处境中，通过人物能力、世界设定和行动结果获得的肯定性满足；它可以表现为成功、反击、成长、关系改善或目标兑现。爽感必须在故事因果中完成，不能只由旁白宣布。

## 读者体验

- 读者知道主角想得到什么、眼下被什么挡住，以及成功会改变什么。
- 主角的行动能改变局面；成长、反击、收获和阶段胜利有铺垫，读者能看懂“为什么这次赢了”。
- 回报对应此前建立的期待，且形式有变化：能力成长、真相揭示、关系推进、认可、资源、脱困等，不反复使用同一种打脸或夸赞。
- 压力、代价和失败风险使胜利有分量，但挫折不能长期遮蔽主角的能动性。

## 写作约束

1. 尽早建立一个可复述的目标、阻碍和行动窗口；开篇信息围绕读者理解这三者组织。
2. 把优势写成可观察的判断、准备、选择和执行。外挂或特殊设定可以提供可能性，不能替代主角作决定。
3. 在兑现前埋下足以回看的条件；反转后让局势、关系或资源发生实际变化。
4. 代价与风险须和情境相称。胜利可以轻快，但不能靠临时改规则或让对手突然失智。
5. 每个章节至少推进目标、改变局面、兑现阶段回报或提出新的有效问题之一；钩子要承接本章事件。

## 避免

- 连续胜利、围观者齐声夸赞或反派降智，取代行动与结果。
- 只堆高数值和新名词，却没有改变主角的选择空间。
- 为制造爽点临时添加规则、抹去已确认代价，或反复重置同一种冲突。
- 把爽文理解为只能快节奏、只能打脸，或不需要人物与情绪积累。

## 与其他规则组合

本规则决定主要满足机制；平台次大类补充目标读者与连载环境，笔风规则决定叙述腔调。遇到冲突，以作品已确认设定和用户明确选择为准；不得仅凭“爽文”标签推断题材、人物关系或尺度。
