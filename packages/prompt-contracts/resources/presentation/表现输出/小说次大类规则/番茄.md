# 番茄

> 用途：面向番茄小说读者与线上连载场景的创作适配建议。平台页面和运营政策会变化；本文件不复述算法、签约条件或审核政策。

## 公开定位与适用范围

番茄小说设有官方作家专区、作者创作指南和作品运作说明，说明其提供面向作者的原创作品管理与创作服务。仅据此不能推断具体推荐算法，也不能断言所有作品都必须采用同一开篇字数、更新频率或题材。

## 面向读者的创作建议

- 尽快让读者看懂主角处境、眼前目标、主要矛盾和继续阅读的理由；先给有效场景，再按需要补背景。
- 使用清楚、顺畅的表达。新设定和专有名词出现时，给出足够的场景线索，不让理解成本阻断冲突。
- 章节持续改变人物处境、关系、认知或目标；阶段性情绪和情节反馈明确，但避免重复同一种刺激。
- 章节钩子从已发生的选择或后果中生长；长线目标要能解释短期冲突为什么值得读。
- 篇幅、题材和更新节奏按当前作品与用户目标制定，不套用未经证实的固定算法阈值。

## 避免

- 用夸张标题或情绪词承诺内容，正文却长时间不兑现核心冲突。
- 为追求“快”省略必要因果，让人物突然做出没有动机的选择。
- 把短句、密集反转或固定开篇模板当成平台强制要求。

## 与其他规则组合

本规则侧重清晰入口、连载反馈和长期承诺；小说大类规则决定主要阅读满足，笔风规则负责叙述声音。若某部作品需要舒缓、复杂或实验性表达，应由用户目标与作品设计决定，不因平台标签自动禁止。
