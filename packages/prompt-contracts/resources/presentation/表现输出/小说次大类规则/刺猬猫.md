# 刺猬猫

> 用途：参考刺猬猫公开呈现的二次元综合阅读与综漫、同人内容生态。这里是面向受众的创作适配，不代表平台全部作品都属于同人或必须使用动漫梗。

## 公开定位与适用范围

刺猬猫官方“关于我们”页面将网站介绍为二次元综合小说阅读网站，并提到综漫小说、宅文同人等内容。该公开定位可作为读者生态线索，但不构成对每部作品题材和写法的强制规定。

## 面向读者的创作建议

- 若使用已有作品、角色或世界观，先核实并遵循用户给定的授权范围与作品设定；明确区分原作事实、同人改写和原创补充。
- 跨作品或混合类型时，为不熟悉全部来源的读者建立入口：用当前行动解释人物关系和关键规则，避免连续点名而没有情境。
- 角色魅力来自目标、选择、声口和关系变化，不只来自原作知名度、属性标签或梗引用。
- 类型奇观和设定服务当前冲突；彩蛋与梗要能增强人物、氛围或情绪，不阻塞故事。
- 原创作品同样适用本平台向规则，不必为了匹配标签硬加入同人、校园或某类网络迷因。

## 避免

- 假设所有读者熟悉每个来源，导致关键动机和因果只靠外部知识补全。
- 把角色写成原作百科条目或梗的搬运载体，缺少本故事中的选择。
- 为“二次元感”随意混用语气、术语和文化背景。

## 与其他规则组合

本规则提供二次元与混合类型读者入口建议；小说大类规则决定主要阅读满足，笔风规则决定叙述方式。涉及作品知识时，以本轮实际读取且用户确认的设定为准，不用平台印象替代证据。

## 来源与适用边界

- 平台介绍不是所有作品的题材清单；本文件保留原创和其他类型的空间。
