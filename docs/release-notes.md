星海余页（StarseaFolio），与智能助手结衣一起，把构思写成长篇故事。

本次更新加入结构化人物档案、逐项编辑与按需添加字段，并完善 Windows 持续发布与更新检测。

- Windows：下载 `Starsea-Folio-*-Setup.exe` 安装，或使用 `Starsea-Folio-*-Portable.exe` 便携包；书库与后端在本机运行，模型服务需自行配置。
- Windows 持续版本：`0.0.1-N`，N 是统一发布流水线分配的递增构建号。应用检测到更高版本后提示下载，由用户确认启动安装向导；安装后保留原有书库和配置。更新设置可调整检查间隔或关闭自动检测，新安装默认每小时检查一次。
- Android：`Starsea-Folio-*-Android-preview.apk` 为开发签名的 Expo 预览客户端，仍依赖 HTTP 后端，尚未内置完整共享工作台与本地后端。Android 维持基础版本，暂不包含 APK 自动更新安装链路。
- 创作流程：讨论文风与主角设定、规划卷主线与支线、逐章完成梗概和大纲，再由草稿经过审核与图治理成为正文。
- 资料管理：Markdown 设定与参考资料配合知识图谱召回证据，支持同人原作核实；检索与抓取效果受来源站点及原作形式影响。
- 兼容已有书库与配置，保留必要的历史存储标识。

源码与使用说明：[StarseaFolio](https://github.com/LastEmbryo2950618641/StarseaFolio)。
