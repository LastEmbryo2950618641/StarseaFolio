# 人物资料结构化存储

用户已授权实施。设定集/人物为不可改名、不可删除的固定目录，新人物一人一个 JSON。现有 Markdown 保留，不做破坏性迁移。

JSON 外层为 schemaVersion=1 与 fields；fields 支持增删改，值为 JSON 值。所有写入由人物字段接口完成，通用 Markdown 写入和 AI 的设定落盘接口不能覆盖人物 JSON。专用工具按需披露参数，读取可沿用文件阅读。世界推演规则/人物设定.md 说明推荐字段、扩展方式和限制。

1. 共享人物文档、字段操作及校验契约。
2. 固定目录、旧书补齐、读写与历史支持；字段原子更新、防止覆盖损坏。
3. 人物字段工具、主角访谈接入、提示词引导与历史记录。
4. 文件树新建人物、人物信息面板、字段编辑保存与扩展。
5. 临时工作区回归测试、类型检查与 DOM 验证；不调用付费模型。
