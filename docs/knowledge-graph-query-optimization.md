# 知识图谱查询定向优化与复测

2026-11-02。本次沿用现有的图谱检索、Source 回查、回答复核方案，修正首轮评测暴露的回答约束问题。没有变更冻结原文、问题或参考答案，没有扩跑全部 120 题或使用保留书调参。

## 问题与实现

首轮 `reed-canal-unknown-future` 的检索已经指出目标事件尚未发生，但 interpret 随后将问题改成当前持有人，draft 仍作确定回答，response_review 用 `evidenceClosed=true` 放行。因此本轮优先修正回答与审核，没有调整图搜索权重来掩盖回答错误。

- interpret 保留原问题的主体、时间、目标事件、资料截止点和真实性条件，禁止用改写后的较容易问题替代原问题。
- source_retrieval 按条件组织已读证据和缺口；当前状态不能证明未来状态，计划和传闻不能当成已完成事实。已确认当前快照缺少目标事件时可以结束检索。
- draft 明确区分只读查询和小说写作。查询不适用创作补全、必须完成正文或不得拒答等要求，并保留用户要求的输出格式。
- response_review 输出 `queryGrounding`，逐项列出条件、支持状态、证据引用和理由；审核原始问题及真实已读证据。
- 查询编排器强制检查审核明细：缺失审核、明确不支持、确定答案存在未知条件或空引用、所有条件已支持却仍拒答，都会退回 draft。沿用原来的三轮审核上限及暂停恢复机制。
- 引用契约校验审核中的 Evidence ID 必须处于本轮可读集合。Schema 保持字段可选以解析旧存档，但执行中的查询必须具备审核明细才能完成。

这些约束能阻止结构上自相矛盾的审核，不能替代语义判断。如果模型把不相关证据错误标为支持，仍可能放行，必须用真实问题继续测量。
